# JavaScript Fundamentals Assignment

A clean, responsive webpage demonstrating core JavaScript concepts for a beginner frontend development assignment.

## Assignment requirements covered

1. **Variable storing a user's name:** `userName` stores the name entered in the form.
2. **Age condition:** an `if...else` statement checks whether `userAge > 18`.
3. **Loop from 1 to 5:** a `for` loop creates and displays the five numbers when the page loads.
4. **Greeting function:** `displayGreeting()` displays a personalised greeting and the age-check result.
5. **Button event:** submitting the form by clicking **Show greeting** calls `displayGreeting()`.
6. **Basic styling:** `style.css` provides a responsive layout, form styling, result messages, and loop number cards.

## Project files

- `index.html` — webpage structure and form controls
- `style.css` — layout, colours, typography, and responsive styles
- `script.js` — variables, validation, condition, loop, and function

## Run the project

1. Extract the project folder if it was downloaded as a ZIP.
2. Open `index.html` in a modern web browser.
3. Enter a name and age, then click **Show greeting**.

No installation, build tools, or external libraries are required.
